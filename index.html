How to play

  • Every tile is an 8-bit number (shown as binary + decimal).
  • Swiping slides tiles; when two collide they XOR:
    0010 ^ 0100 = 0110 — different bits combine.
  • Equal tiles cancel: 0011 ^ 0011 = 0000 — your "delete" tool.
  • Overlapping bits are lost: 0110 ^ 0011 = 0101 — wasted potential.
  • Goal: forge the full register 11111111 = 255.
  • Score = total bits set on merges. No lose state — it's a puzzle, take your time.
  • Every tile is an 8-bit number. Collisions have three outcomes.
  • No shared bits → combine.
    0010 | 0100 = 0110. Score is the new tile's bit count, squared.
  • Equal tiles → annihilate.
    0011 + 0011 = gone — your only way to clear a jam.
  • Any shared bit → block.
    0110 and 0011 both hold bit 2, so they stop dead against each other. This is what fills the board.
  • A forged 11111111 overlaps everything, so it is a wall. The only thing that clears it is a second one.
  • No goal — play for score. The board fills, and you lose when nothing can move.
